# Система зворотного зв'язку для батьків (Parents Feedback System)

Локальна ергономічна система обліку уроків та збору зворотного зв'язку від учителя по роботі учнів із можливістю автоматичного формування звітів та промптів для штучного інтелекту (для надсилання повідомлень батькам).

---

## 🚀 Швидкий запуск

1. Перейдіть до каталогу проєкту:
   ```powershell
   cd E:\_pet\_parents_feedback_system
   ```
2. Запустіть локальний сервер:
   ```powershell
   npm run dev
   ```
3. Відкрийте у браузері: [http://localhost:5173](http://localhost:5173)

---

## 🎯 Ключові можливості

1. **Групування уроків за датами**:
   - Колонки згруповані за кожним уроком (наприклад, 4 уроки на тиждень).
   - Відображення дати, номера уроку (№1, №2...) та теми заняття.
2. **Єдина шкала оцінювання від 0 до 12 балів**:
   - Оцінювання різних видів діяльності: *Поведінка*, *Стан дитини*, *Працездатність*, *Оцінка за урок*, *Активність*, *Покращення*.
   - Гнучке додавання власних критеріїв діяльності у вікні **«Критерії (0-12)»**.
   - Кольорове маркування балів для швидкого візуального сприйняття:
     - 🟢 **10–12** — високий рівень
     - 🔵 **7–9** — достатній рівень
     - 🟡 **4–6** — середній рівень
     - 🔴 **1–3** — початковий рівень
3. **Класи та категорії (6-А, 6-Б тощо)**:
   - Швидке перемикання між класами у верхній панелі.
   - Створення та налаштування класів.
   - Додавання учнів до відповідного класу із зазначенням індивідуальних особливостей.
4. **Колонки та поля для приміток**:
   - **Загальні примітки про учня**: закріплена колонка для довгострокових спостережень вчителя.
   - **Примітки до уроку**: швидке поле у кожному уроці для фіксації деталей заняття ("забув зошит", "активна відповідь біля дошки").
5. **Помічник ШІ та звіти для батьків**:
   - При натисканні на зірочку ✨ біля учня відкривається аналітична картка.
   - Підрахунок середніх балів та динаміки за всіма уроками.
   - Кнопка **«Скопіювати промпт для ШІ»**: формує структурований готовий запит для ChatGPT / Claude / Gemini для створення тактовного, теплого повідомлення батькам у Viber або Telegram.
6. **Повна автономність (Локальний JSON)**:
   - Не потребує важкої серверної БД.
   - Дані автоматично зберігаються у фізичний файл `data/database.json`.
   - Доступні функції **Експорту** та **Імпорту** резервних копій JSON.

## 🤖 Екосистема ШІ-агентів (за зразком school-base)

У проєкті налаштовано мультиагентне середовище та суворі стандарти якості:
- **Конституція проєкту** [`.spec/constitution.md`](file:///.spec/constitution.md): вищий закон (українська мова UI, обов'язкові toast-сповіщення, модульність, 4-крокова перевірка).
- **Інструкції для агентів** [`AGENTS.md`](file:///AGENTS.md) та [`GEMINI.md`](file:///GEMINI.md).
- **CodeGraph**: індексація та розуміння кодової бази через `codegraph explore`.
- **Навички (`.agents/skills/`)**:
  - `ponytail`, `ponytail-review`, `ponytail-audit`: філософія "Lazy Senior Developer" — економія коду, відмова від оверінжинірингу та надлишкових бібліотек.
  - `bmad-agile-workflow`, `spec-driven-development`: агент-архітектор та планування фіч.
  - `subagent-driven-development`: ізольовані кодинг-субагенти.
  - `frontend-modularity`, `good-taste`: стандарти чистоти коду та UI.
  - `testing-vitest`, `verification-before-completion`, `systematic-debugging`: контроль якості.

## 🔒 Розгортання на PHP хостингу та захист даних

Система повністю готова для розміщення на будь-якому стандартному PHP хостингу (Apache/LiteSpeed/Nginx):

1. **Збірка проєкту:**
   ```powershell
   npm run build
   ```
2. **Завантаження файлів на хостинг:**
   - Папка `dist/` (зібраний інтерфейс).
   - Папка `data/` разом із файлом `.htaccess` (блокує пряме скачування `database.json`).
   - Файли `index.php`, `api.php`, `config.php`.
3. **Налаштування пароля:**
   - Відкрийте `config.php` на хостингу та замініть пароль за замовчуванням `teacher2026` на власний надійний пароль.
4. **Права доступу на хостингу:**
   - Переконайтеся, що папка `data/` та файл `data/database.json` мають права на запис для веб-сервера (`chmod 775` або `chmod 777` залежно від налаштувань хостингу).
