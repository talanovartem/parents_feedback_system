# Зміни для коментарів, синхронізації та бонусів KP

## Коментарі для батьків

- У журналі біля імені учня з'являється кнопка копіювання найновішого збереженого коментаря.
- Попередні коментарі доступні незалежно від активного періоду.
- Пакетний імпорт дозволяє вручну зіставити неоднозначні імена, попереджає про заміну тексту та показує успіх після підтвердження запису.

## Синхронізація

- Клієнт послідовно записує зміни й надсилає ревізію через `If-Match`.
- PHP перевіряє ревізію під блокуванням файлу та повідомляє про невдалий запис.
- За конфлікту або збою непідтверджені дані залишаються в браузері; їх можна експортувати як JSON.

## Бонуси KP

- У навігації є сторінка «Бонуси KP» (`#/kp`).
- За замовчуванням вибрано всі класи; можна вибрати будь-яку комбінацію.
- Період: поточний чи минулий тиждень, навігація по інших тижнях або довільні дати.
- Значення KP можна задати окремо кожному учню або всім вибраним одразу.
- Є вкладки нарахувань, балансів учнів та історії з пошуком.

## Перевірка

`npm run typecheck`, `npm run lint`, `npm run test` (71 тест) і `npm run build` пройшли. Сторінку KP відкрито в локальному браузері; перевірено вибір двох класів та вкладку балансів. На бойовому PHP-хостингу зміни ще не перевірялись і не розгортались.
